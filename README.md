Uma aplicação de vitrine virtual moderna e responsiva desenvolvida em React, consumindo dados da **FakeStoreAPI**. O projeto utiliza a biblioteca de componentes **PrimeReact** e o motor de utilitários CSS **PrimeFlex** para um design limpo e eficiente.

---

## 🚀 Tecnologias Utilizadas

* **React.js**: Biblioteca principal para construção da interface.
* **PrimeReact**: Suite de componentes UI premium.
* **PrimeFlex**: Utilitários CSS baseados em classes para layout e espaçamento.
* **Axios**: Cliente HTTP para consumo de APIs.
* **FakeStoreAPI**: API REST pública para fornecer dados de produtos reais.

---

## 📦 Funcionalidades

- [x] Consumo dinâmico de produtos via API.
- [x] Listagem de produtos em formato de Grid Responsivo.
- [x] Cards detalhados com título, preço, categoria e descrição.
- [x] Badge de avaliação (rating) posicionado sobre a imagem do produto.
- [x] Layout otimizado com `object-fit: contain` para garantir a integridade das imagens.
